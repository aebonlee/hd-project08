# 마케팅 파트 업무공유 대시보드

HD건설기계 AMPS기획팀 마케팅 파트의 업무 공유용 단일 페이지 대시보드입니다.

> **참고**: 기존에 사용하던 대시보드 링크가 아직 공유되지 않아, 일반적인 마케팅 팀 업무공유
> 대시보드의 **표준 템플릿**으로 우선 제작했습니다. 실제 화면을 확인한 뒤 섹션 구성·항목을
> 조정할 수 있습니다.

## 실행 방법

서버 없이 브라우저만으로 동작합니다.

```
dashboard_marketing/index.html 파일을 브라우저(크롬 권장)로 열기
```

- 처음 열면 샘플 데이터가 표시됩니다.
- 화면에서 수정한 내용은 **localStorage에 자동 저장**되어 새로고침해도 유지됩니다.
  (같은 PC·같은 브라우저 기준. 다른 사람과 공유하려면 엑셀 내보내기/가져오기를 사용하세요.)

## 화면 구성

| 섹션 | 내용 |
|---|---|
| 상단 KPI | 진행 중 캠페인 수(진행+검토) · 이번 주 마감 업무(미완료) · 지연 항목 · 이번 달 완료율 |
| 캠페인/프로젝트 현황 | 카드 보드. 상태 칩 필터(기획/진행/검토/완료/보류), 카드 클릭 시 인라인 수정 폼, 추가/삭제 |
| 담당자별 업무 현황 | 담당자 칩 필터, 상태 인라인 변경, 추가/삭제. **마감 경과+미완료 업무는 빨간색 "지연" 표시** |
| 주간 일정 | 월~금 컬럼 보드, 이전/다음 주 이동, 회의·마감·행사 구분, 추가/삭제 |
| 채널 성과 요약 | 채널별 미니 카드(당월 값 + 전월 대비 증감), 카드 클릭 시 최근 6개월 추이 라인 차트 전환 |
| 공지/이슈 게시판 | 상단 고정 공지 + 목록(중요도·작성자·날짜), 추가/삭제 |

## 엑셀 가져오기 / 내보내기

상단의 [엑셀 내보내기]로 현재 데이터를, `templates/` 폴더에서 양식을 받을 수 있습니다.

- `templates/marketing_template.xlsx` — 빈 업로드 양식 (헤더 + 작성 안내)
- `templates/marketing_sample.xlsx` — 샘플 데이터가 채워진 예시 (화면의 샘플과 동일)

**시트 구성** (시트명이 정확히 일치해야 인식됩니다. 일부 시트만 있어도 해당 시트만 반영):

| 시트명 | 컬럼 |
|---|---|
| `캠페인` | ID, 캠페인명, 브랜드(Hyundai/Develon/공통), 상태(기획/진행/검토/완료/보류), 진행률(%), 담당자, 시작일, 종료일, 다음 마일스톤 |
| `업무` | ID, 업무명, 관련 캠페인, 담당자, 우선순위(높음/중간/낮음), 마감일, 상태(대기/진행/완료) |
| `주간일정` | ID, 날짜, 시간, 구분(회의/마감/행사), 일정명 |
| `채널실적` | 월(YYYY-MM), 채널, 값 |
| `공지` | ID, 고정(Y/N), 중요도(높음/보통), 제목, 작성자, 날짜 |

- 날짜는 `YYYY-MM-DD` 권장 (엑셀 날짜 셀 서식도 자동 인식)
- ID는 비워도 자동 부여됩니다.

양식 재생성: `python3 make_samples.py` (openpyxl, node 필요 — 샘플 값은 `js/sample-data.js`에서 읽어와 항상 화면 샘플과 일치)

## 파일 구조

```
dashboard_marketing/
├── index.html          # 단일 페이지 진입점
├── css/style.css       # HD 계열 코퍼레이트 라이트 테마(네이비 포인트)
├── js/
│   ├── logic.js        # 순수 계산 로직 (지연 판정·완료율·주간 계산) — Node에서도 동작
│   ├── data.js         # 데이터 계층 (localStorage 저장, 엑셀 시트 ↔ 상태 변환)
│   ├── sample-data.js  # 샘플 데이터 (엑셀 샘플과 동일 내용)
│   └── app.js          # UI 렌더링·이벤트
├── test/logic.test.js  # 로직 테스트
├── templates/          # 엑셀 업로드 양식 + 샘플
└── make_samples.py     # 양식/샘플 xlsx 생성 스크립트
```

사용 라이브러리(로컬 동봉, CDN 불필요): `../lib/xlsx.full.min.js`(SheetJS), `../lib/chart.umd.min.js`(Chart.js 4)

## 테스트

```
cd dashboard_marketing
node test/logic.test.js
```

지연 판정, 이번 주 마감/완료율 KPI, 주간(월~금) 계산, 필터, 엑셀 변환 왕복 등 30개 케이스를 검증합니다.

## 주요 규칙

- **지연**: 마감일이 오늘 이전이고 상태가 "완료"가 아닌 업무 (오늘 마감은 지연 아님)
- **이번 주 마감**: 이번 주 월~일 사이 마감 & 미완료
- **완료율(월)**: 이번 달에 마감일이 있는 업무 중 완료 비율
- **진행 중 캠페인**: 상태가 진행 또는 검토

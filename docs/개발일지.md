- 저장소: https://github.com/aebonlee/hd-project08

## 1. 요구사항 분석

### 입력 자료
- 기획서 PPTX(뉴스레터 대시보드): 기존 Antigravity 제작 화면 스크린샷 4종 + 디벨론 공식 브랜드 컬러 가이드 + 요구사항 주석
- 부품 사진 파일명 실제 예시 스크린샷: `001_15KA-72040_(HYUNDAI CONSTRUCTION EQUIPMENT).JPG` 형식 확인
- 마케팅 업무공유 대시보드는 기존 링크 미제공 → 표준 템플릿으로 제작 후 실제 화면 확인 시 조정

### 핵심 요구
1. **뉴스레터 대시보드**: 단순 수정이 아닌 업그레이드/재제작 — 현대·디벨론 브랜드별 디자인 가이드 적용, 엑셀 업로드만으로 자동 업데이트(코딩 불필요), 세계지도 위 지역별 오픈율, 결과 분석 AI 자동 기입, 여백 등 디자인 완성도
2. **부품 사진 자동화**: 기존 시도의 오류(텍스트/숫자 오독, 브랜드 오독, 같은 부품의 품번 이어받기 실패)를 해결한 "깔끔한 AI 자동화"
3. API 키는 Claude·ChatGPT·Solar 등 사용 가능하게 (기획자 확인 사항)

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| 4개 도구를 한 저장소의 독립 폴더 + 허브 페이지로 구성 | 각 도구를 개별적으로 이어서 개발 가능, GitHub Pages 하나로 전부 배포 |
| 라이브러리 전부 로컬 동봉 (SheetJS·Chart.js·Tesseract·JSZip) | CDN 미의존 — 오프라인·사내망 대응, 기본 OCR은 언어데이터까지 동봉해 사진이 외부로 나가지 않음 |
| **[뉴스레터]** CSS 변수 기반 브랜드 테마 6종 (현대/디벨론/ALL × 라이트/다크) | 디벨론 공식 가이드(#FF5F00, Charcoal #161616, Exo 폰트, 보조색 단독 사용 금지) 준수, 브랜드 전환 시 자동 적용 |
| **[뉴스레터]** 세계지도는 인라인 SVG 실루엣 + 지역 버블(크기=수신자, 농도=오픈율) | 외부 지도 라이브러리 없이 안정 동작, 순위 막대 리스트를 텍스트 대안으로 병행 |
| **[뉴스레터]** 결과 분석은 규칙 기반 5종 자동 생성 + LLM 어댑터 지점 문서화 | API 키 없이도 항상 동작, 사내 정책 확정 시 LLM 연동으로 고도화 |
| **[사진]** OCR 혼동 문자 정규화(O↔0, I↔1, S↔5, B↔8)로 같은 부품 판정 | 기존 오류의 핵심이던 "같은 품번을 다른 품번으로 오인"을 구조적으로 방지 (실제 다른 숫자는 구분 유지) |
| **[사진]** 검수(Human-in-the-loop) 화면을 필수 단계로 | AI 오인식을 전제로 설계 — 그룹 분리/합치기, 품번·브랜드 수정이 그룹 전체 반영 |
| **[사진]** 인식 엔진 어댑터 4종 (Tesseract 무료 / Claude / OpenAI / Upstage) | 기획자 요청대로 API 키 선택 사용, 키는 브라우저 localStorage에만 저장 |
| **[사진]** 적용 방식 3종 (폴더 직접 변경 / ZIP / .bat 스크립트) | 브라우저·보안 환경 차이에 관계없이 실무 적용 가능 |

## 3. 구현 내역

### 뉴스레터 결과보고 대시보드 (`dashboard_newsletter/`)
- 사이드바 필터(브랜드/월/대상/지역 12개), KPI 4종(전월 대비 ▲▼), 세계지도+도넛 게이지 탭, 그룹별 성과 표, 콘텐츠 클릭 순위, 클릭 빈도 분포, VIP 독자 Top5(가상 이메일), 월별 추이(발송건수 콤보 옵션), ALL 화면 브랜드 비교 2종
- 결과 분석 자동 기입(최고 지역/전월 변화/모수 기여/저조 지역 제안/콘텐츠 시사점, 01~05 형식 + 복사)
- 엑셀 업로드: 3시트 양식(발송실적/콘텐츠클릭/독자클릭), 시트·컬럼명 유사 매핑, 행 단위 검증·매핑 리포트. 양식·샘플 xlsx 제공
- 내보내기: 차트 PNG, PDF 인쇄, 필터 결과 엑셀

### 마케팅 파트 업무공유 대시보드 (`dashboard_marketing/`)
- KPI(진행 캠페인/이번 주 마감/지연/월 완료율), 캠페인 카드 보드(상태·진행률·인라인 수정), 담당자별 업무 표(지연 하이라이트), 주간 월~금 일정 보드, 채널 성과(당월 카드+6개월 추이), 공지 게시판
- localStorage 유지 + 5시트 엑셀 임포트/내보내기(왕복 검증), 양식·샘플 xlsx

### 부품 사진 파일명 자동화 (`photo_renamer/`)
- `연번3자리_품번_(브랜드).JPG` 규칙 (실제 예시 그대로), 새 부품 전까지 품번·브랜드 이어받기, 시작 연번 조정
- 인식: 품번 패턴 점수화, 브랜드 사전(편집 가능) + 퍼지 매칭, 신뢰도 표시
- 검수 UI → 적용(폴더 실제 변경/ZIP/.bat) + 매핑 CSV. 연습용 샘플 사진 7장 동봉

### 회의록 정리 도우미 (`meeting_notes/`)
- 메모 → 결정/논의/액션 규칙 분류(담당자·기한 추출 포함), 표준 회의록 렌더, 항목 이동·인라인 수정, 마크다운 복사/.md/인쇄, 사내 AI용 프롬프트 템플릿 생성

## 5. 트러블슈팅

| 이슈 | 해결 |
|---|---|
| 품번 동일 판정이 과도해 `72040`≠`71040` 구분 실패 | 혼동 문자 정규화 후 **완전 일치**로 엄격화 (편집거리 허용 제거) — 테스트로 고정 |
| 브랜드 퍼지 매칭이 복합어 첫 단어만으로 오매칭 | 브랜드의 모든 단어가 발견될 때만 퍼지 매칭 허용 |
| 기획서 스크린샷의 VIP 독자 실제 이메일 | 샘플 데이터는 전부 가상 이메일(@example.com)로 생성, 실제 주소 미사용 |
| 캠페인 인라인 수정 폼이 카드 폭을 넘침 | 수정 중 카드를 전체 행 폭으로 전환 |
| "금요일까지"를 금요일에 입력하면 다음 주로 계산 | 기준일 자정 정규화로 해결 |

## 7. 이어서 개발하실 분께 (향후 과제)

- **뉴스레터**: 기존 Antigravity 대시보드 링크 공유 시 세부 레이아웃 맞춤. 결과 분석의 LLM 연동(README의 어댑터 지점), 실제 뉴스레터 플랫폼(예: Stibee/Mailchimp) 내보내기 데이터로 업로드 양식 컬럼 확정
- **마케팅**: 실제 화면 확인 후 섹션 구성 조정, 구글 시트/그룹웨어 연동
- **부품 사진**: 실무 사진으로 브랜드 사전·품번 패턴 보강 (`js/logic.js`의 `DEFAULT_BRANDS`·`PART_RE`), 모바일 촬영 직후 처리 흐름(PWA) 검토
- **회의록**: 분류 규칙 추가(`meeting_notes/js/logic.js`), 사내 AI API 직접 연동

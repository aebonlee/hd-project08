# 회의록 정리 도우미

회의 중 자유롭게 받아 적은 메모를 붙여넣으면 **규칙 기반**으로
①결정 사항 / ②액션 아이템 / ③논의 내용 3가지로 분류하여 표준 회의록 양식으로 만들어 주는
경량 단일 페이지 도구입니다. 외부 AI API를 호출하지 않으며, 모든 처리는 브라우저 안에서 이루어집니다.

## 실행 방법

```
meeting_notes/index.html 파일을 브라우저(크롬 권장)로 열기
```

- [샘플 메모 불러오기]로 마케팅 회의 예시를 바로 확인할 수 있습니다.
- 작성 중인 회의 정보·메모·정리 결과는 **localStorage에 자동 저장**되어 새로고침해도 유지됩니다.

## 사용 흐름

1. **좌측**: 회의 정보(제목/일시/참석자/작성자/다음 회의)와 회의 메모를 자유 형식으로 입력
2. **[정리하기]**: 줄 단위로 분류하여 우측에 표준 회의록(개요 → 논의 내용 → 결정 사항 → 액션 아이템 표 → 다음 회의) 렌더
3. **수정**: 각 항목의 [→결정] [→논의] [→액션] 버튼으로 분류를 이동, 액션의 담당·기한은 표에서 바로 편집 (비어 있으면 붉게 표시)
4. **내보내기**: 클립보드 복사(마크다운) / `.md` 다운로드 / 인쇄(PDF — 브라우저 인쇄에서 "PDF로 저장")

## 분류 규칙 (우선순위 순)

| 순위 | 신호 | 분류 |
|---|---|---|
| 1 | `TODO` · `액션` · `A/I` · `@이름` · `담당: 이름` 등 명시적 액션 마커 | 액션 아이템 |
| 2 | `결정` · `확정` · `~하기로 함` · `승인` · `합의` · `채택` 등 | 결정 사항 |
| 3 | `이름이/가 ~까지` 패턴, 또는 `~까지` + 액션성 동사(제출/공유/작성/보고 등) | 액션 아이템 |
| 4 | 그 외 모든 줄 | 논의 내용 |

규칙 기반이므로 오분류가 있을 수 있습니다 — 결과 화면의 이동 버튼으로 바로잡는 것을 전제로 설계했습니다.

### 담당자 추출
`@이름` → `담당: 이름` → `이름이/가 ~까지` → 줄 앞 `이름:` 순으로 시도. 없으면 "미정".

### 기한 추출 (기준일: 정리하기를 누른 날)
- `2026-09-01`, `9/4`, `9월 4일` → `YYYY-MM-DD`로 정규화
- `오늘` / `내일` / `모레` / `월말` / `이번 주` / `다음 주`
- `금요일까지`, `다음 주 화요일` 등 요일 표현 (이미 지난 요일은 다음 주로 해석)
- 없으면 "미정" (표에서 직접 입력 가능)

## AI 프롬프트 템플릿 탭

사내 Copilot·LLM 채팅창에 붙여넣을 수 있는 **회의록 정리 프롬프트**를 생성합니다.
좌측에 입력한 회의 정보와 메모가 자동으로 삽입된 완성형 프롬프트이며 [프롬프트 복사] 버튼으로 복사합니다.
이 도구 자체는 외부 API를 호출하지 않습니다.

## 파일 구조

```
meeting_notes/
├── index.html          # 단일 페이지 진입점
├── css/style.css
├── js/
│   ├── logic.js        # 순수 로직 (분류·담당/기한 추출·마크다운/프롬프트 생성) — Node에서도 동작
│   └── app.js          # UI 렌더링·이벤트·localStorage 저장
└── test/logic.test.js  # 로직 테스트
```

외부 라이브러리 의존성 없음 (순수 HTML/CSS/JS).

## 테스트

```
cd meeting_notes
node test/logic.test.js
```

줄 분류, 담당자/기한 추출(날짜 정규화 포함), 항목 이동, 마크다운/프롬프트 생성 등 34개 케이스를 검증합니다.
